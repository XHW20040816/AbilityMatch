# 数据库表结构说明

数据库：`AbilityMatch.db`（HarmonyOS RelationalStore，securityLevel S1，应用沙盒内）
建表来源：`entry/src/main/ets/common/Constants.ets` 的 `CREATE_SQLS`

## 1. 表清单

| 序号 | 表名 | 说明 | 类别 |
| --- | --- | --- | --- |
| 1 | student_info | 学生信息表 | 核心 |
| 2 | honor_certificate | 荣誉证书表 | 核心 |
| 3 | ability_tag | 能力标签表 | 核心 |
| 4 | company_info | 企业信息表 | 核心 |
| 5 | job_requirement | 岗位需求表 | 核心 |
| 6 | match_record | 匹配记录表 | 核心 |
| 7 | growth_plan | 成长计划表 | 核心 |
| 8 | honor_search_token | 荣誉倒排索引表 | 辅助 |
| 9 | skill_certificate | 技能证书表 | 辅助 |
| 10 | project_experience | 项目经历表 | 辅助 |
| 11 | user_account | 账号表 | 辅助 |
| 12 | app_meta | 结构与配置元数据表 | 辅助 |

## 2. student_info（学生信息表）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| student_no | TEXT | NOT NULL, UNIQUE | 学号，登录关联与学生唯一标识 |
| name | TEXT | NOT NULL | 姓名 |
| school | TEXT | DEFAULT '' | 学校 |
| school_level | TEXT | DEFAULT '' | 学校层级：985/211/普通本科/其他 |
| major | TEXT | - | 专业 |
| grade | TEXT | - | 年级：大一~大四/研一~研三 |
| education | TEXT | DEFAULT '本科' | 学历：专科/本科/硕士/博士 |
| direction | TEXT | - | 专业方向（Taxonomy 统一词表） |
| phone | TEXT | - | 手机号 |
| email | TEXT | - | 邮箱 |
| is_public | INTEGER | DEFAULT 1 | 是否公开求职档案（1 公开 / 0 仅自己可见） |
| create_time | INTEGER | NOT NULL | 创建时间（毫秒） |
| update_time | INTEGER | NOT NULL | 更新时间（毫秒） |

## 3. honor_certificate（荣誉证书表）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK | 主键 |
| student_id | INTEGER | NOT NULL, FK→student_info(id) CASCADE | 所属学生 |
| title | TEXT | NOT NULL | 证书/奖项名称 |
| honor_type | TEXT | NOT NULL | 荣誉类型：学科竞赛/荣誉称号/奖学金/专利软著等 |
| level | TEXT | - | 级别：国家级/省级/市级/校级/院级 |
| award_year | INTEGER | - | 获奖年份（用于年份区间筛选） |
| issuer | TEXT | - | 颁发单位（用于单位筛选与归档） |
| image_path | TEXT | - | 奖状图片相对路径（沙盒 images 目录） |
| remark | TEXT | - | 备注 |
| search_text | TEXT | - | 归一化检索文本（模糊兜底） |
| create_time | INTEGER | NOT NULL | 创建时间 |
| update_time | INTEGER | NOT NULL | 更新时间 |

## 4. honor_search_token（倒排索引表）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK | 主键 |
| student_id | INTEGER | NOT NULL | 冗余学生 ID，便于按学生过滤 |
| honor_id | INTEGER | NOT NULL, FK→honor_certificate(id) CASCADE | 所属荣誉 |
| token | TEXT | NOT NULL | 分词结果（单字 + 双字 n-gram） |

## 5. ability_tag（能力标签表）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK | 主键 |
| student_id | INTEGER | NOT NULL, FK→student_info(id) CASCADE | 所属学生 |
| tag_name | TEXT | NOT NULL | 标签名 |
| category | TEXT | NOT NULL | 类别：SKILL/CERT/HONOR/PROJECT |
| source_type | TEXT | - | 来源：AUTO（抽取）/MANUAL（手动） |
| source_id | INTEGER | - | 来源记录 ID |
| proficiency | INTEGER | DEFAULT 3 | 熟练度 1-5 |
| confidence | REAL | DEFAULT 1.0 | 置信度 0-1 |
| create_time | INTEGER | NOT NULL | 创建时间 |

唯一约束：`(student_id, tag_name, category)`，避免同一学生同类标签重复。

## 15. 约束与一致性设计

1. **外键与级联删除**：`growth_plan`、`honor_certificate`、`ability_tag`、`skill_certificate`、`project_experience`、`match_record` 均以 `student_id` 外键关联学生；`match_record.job_id`、`job_requirement.company_id`、`honor_search_token.honor_id` 同样建立外键，统一 `ON DELETE CASCADE`。删除学生/企业/岗位时下级数据自动清理，避免孤儿数据。启动时执行 `PRAGMA foreign_keys = ON`。
2. **事务**：多表写入（证书 + 标签 + 倒排索引、技能证书 + 标签、项目 + 标签）统一通过 `DbHelper.runInTransaction` 提交，任一失败整体回滚。
3. **唯一约束**：`student_info.student_no`、`user_account.account`、`ability_tag(student_id, tag_name, category)`、`honor_search_token(honor_id, token)`；建唯一索引前先做重复数据清理，保证在有历史数据的库上也能创建成功。
4. **结构版本**：`app_meta.schema_version` 记录结构版本（当前 2），迁移采用“列存在性判断 + 版本记录”双保险，保证旧库升级幂等；后续新增字段时递增 `Constants.DB_VERSION` 并追加迁移分支。
5. **备份与恢复**：全表 JSON 快照导出/导入，恢复在单事务内先清空后导入，并对表名做白名单校验、对文件大小设 20MB 上限。
