## 6. 缺口清单（按优先级）

### 6.1 G-01 匹配记录被覆盖（影响 FR-19，优先级高）

`JobListPage.ets:34` 与 `CandidatePage.ets:63` 在加载前分别调用 `clearStudentJobRecords` / `clearJobCandidateRecords`，然后重新计算并插入。结果：`match_record` 表永远只保留“最近一次进入列表”的快照，无法回溯历史分数。

改动建议（三选一，成本都很低）：

- 方案 A：去掉 clear 调用，插入前按 `(student_id, job_id, direction)` 覆盖当日记录，其余保留；
- 方案 B：保留 clear，但改为只删除 `create_time` 早于 30 天的记录，实现“保留近 30 天”；
- 方案 C：不改写入，改 `MatchRepository.listByStudent/listByJob` 前先做 `GROUP BY job_id` 取最新，页面按岗位聚合展示。

**修复（2026-11-22，采用方案 A）**：新增 `MatchRepository.replaceToday(record)`，先删除当日 `(student_id, job_id, direction)` 相同的记录再插入；`JobListPage`、`CandidatePage` 去掉 `clear*Records` 调用，改用 `replaceToday`。跨天历史完整保留，同日重复进入不会爆炸增长；主 HAP 在 API 26 模拟器构建通过。

### 6.2 G-02 CSV 导出中文兼容（优先级中）

`ExportService` 直接以 UTF-8 写入 `标题,荣誉类型...`，未写 BOM。Windows Excel 双击打开可能把中文识别为乱码。建议在内容前拼 `\uFEFF`，或在导出说明中注明“用 Excel 时请以 UTF-8 方式导入”。

**修复（2026-11-22）**：`ExportService.certificatesCsv()` 返回内容前置 `\uFEFF`，Windows Excel 双击可正确识别中文。

### 6.3 G-03 性能数据缺失（优先级中）

题目非功能需求写了“1000 条证书下检索 < 1 s”，但没有任何实测记录。补测方法：写一个 Hypium 用例，批量 `insert` 1000 条 `honor_certificate`，用 `Date.now()` 包住 `HonorRepository.list(studentId, filter, 20, 0)` 与 `count`，记录 P50/P95 耗时，写入测试报告即可闭环。

**已补数据（2026-11-22）**：新增 `entry/src/ohosTest/ets/test/CertSearchPerf.test.ets`，事务写入 1000 条荣誉后各重复 20 次。结果：关键字检索 avg 17.05 ms / p95 45 ms / max 45 ms；计数查询 avg 6.45 ms；无命中检索 avg 5.55 ms。1000 行规模下远低于 1 s 判据。完整采样见 `docs/perf_cert_search.json` 与 `05-系统测试报告.md` 第 7 节。

### 6.4 G-04 API 12 未实机回归（优先级中）

`compatibleSdkVersion` 已声明 12，但只在 API 26 SDK 上构建与运行。若答辩要求“API 12 可运行”，需在 API 12 镜像模拟器上安装一次并走主流程；`cameraPicker`、`reminderAgentManager`、`Canvas` 是三个最可能受版本影响的点。

**进展（2026-11-22）**：本轮修复后，主 HAP 与 ohosTest HAP 在 `compatibleSdkVersion 5.0.0(12)` 下均构建通过（编译器按兼容版本做 API 可用性校验），单元 / UI / 性能测试通过；本次改动仅使用 `relationalStore` 事务（API 9+）与标准 `Date`，无 API 12 以上新依赖。真机 API 12 走主流程仍需有 API 12 设备时补跑。

### 6.5 G-05 成长方向覆盖偏少（优先级低）

只有“软件开发 / 嵌入式”两个方向。扩展只需在 `growth_templates.json` 增加 `direction` 分组，页面 `Select` 改为按 JSON 动态生成即可。

## 8. 答辩演示建议（5 分钟覆盖全部要求）

1. 首页切“学生端 / 企业端”，说明同一学生不同视角。
2. 成长规划：切方向与阶段 → 勾选任务 → 设置提醒 → 回到首页看逾期提示。
3. 荣誉证书：拍照/选图 → 填四类归档字段 → 关键字 + 类型 + 级别 + 年份组合筛选 → 上拉分页 → 点图预览 → 导出 CSV。
4. 能力画像：加技能证书与项目 → 看五维雷达与标签 → 编辑/删除 → 导出 JSON。
5. 招聘发布：粘贴简章（含“本科及以上、3 年经验、熟悉 Java/Spring Boot、持有 CET-6”）→ 看解析结果 → 调权重 → 发布。
6. 学生岗位列表（按分排序）→ 岗位详情看差距与建议。
7. 企业候选人：选企业 → 选岗位 → 点候选人看详情（五维分、差距、建议）。
8. 匹配记录回溯。

> 演示前务必准备一条能触发“缺技能 / 缺证书 / 经验不足”三类差距的简章，否则差距项与建议展示不充分。
