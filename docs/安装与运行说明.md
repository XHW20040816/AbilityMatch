# 安装与运行说明

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11（开发）、HarmonyOS 真机或模拟器（运行） |
| 开发工具 | DevEco Studio 5.0 及以上 |
| SDK | HarmonyOS SDK，compatibleSdkVersion 5.0.0(12)，即 API 12 及以上 |
| 设备 | HarmonyOS NEXT（API 12+）真机或 DevEco 模拟器 |
| 构建命令 | hvigorw（无需命令行登录华为账号） |

## 2. 已构建产物

| 产物 | 路径 |
| --- | --- |
| Release 签名 HAP | `dist/AbilityMatch-1.0.0-release-signed.hap` |
| Debug 签名 HAP | `entry/build/default/outputs/default/entry-default-signed.hap` |

HAP 使用 DevEco Studio 自动生成的调试证书（`signingConfigs.default`）签名，可直接安装到本地模拟器或开发者模式真机。

## 3. 构建

```powershell
# 构建 Debug 包
hvigorw --mode module -p product=default assembleHap

# 构建 Release 包（已开启 release 编译选项）
hvigorw --mode module -p product=default -p buildMode=release assembleHap
```

## 4. 安装与启动

```powershell
# 查看已连接设备
hdc list targets

# 安装（-r 覆盖安装，保留应用沙盒数据）
hdc install -r dist\AbilityMatch-1.0.0-release-signed.hap

# 启动
hdc shell aa start -a EntryAbility -b com.example.abilitymatch

# 卸载（含沙盒数据清理）
hdc uninstall com.example.abilitymatch
```

也可在 DevEco Studio 中直接点击 Run/Debug 运行。

## 6. 功能入口速查

**学生端**
- 首页：按年级自适应排列模块（低年级优先成长规划，高年级优先能力画像/岗位匹配）
- 能力画像：标签管理、技能证书、项目经历、荣誉缩略图、导出 HTML 档案 / 导出画像长图
- 荣誉证书：关键字检索（倒排索引）、类型/级别/年份区间/颁发单位筛选、拍照或相册录入、图片预览
- 成长规划：按方向与学年阶段生成任务、完成率/逾期统计、学期进度、提前提醒与逾期再提醒
- 岗位匹配：岗位列表（方向筛选 + 关键字搜索）、匹配得分明细、差距项与补齐建议
- 学生资料：学历/学校层级/专业方向、公开求职档案开关
- 个人中心：匹配记录、数据工具、退出

**企业端**
- 企业信息：营业执照/企业证明、核验状态（本地模拟审核，含撤回为待审核）
- 发布岗位：粘贴招聘简章，自动抽取学历/技能/证书/经验要求并生成岗位模型
- 候选人列表：按岗位查看候选人，支持方向过滤与分页
- 候选人详情：匹配得分明细与差距项

**数据工具（学生端/企业端均有）**
- 导出备份（JSON 快照）
- 从备份恢复
- 生成 20 名演示学生（便于演示分页、筛选与匹配性能）
- 图片与缓存占用统计、清理缩略图
- 重置演示数据（清空业务数据并重建种子数据）

## 7. 常见问题

1. **安装提示签名校验失败**：确认设备为开发者模式，或使用 DevEco Studio 重新签名（Project Structure → Signing Configs → Automatically generate signature）。
2. **提醒不弹出任务栏通知**：首次设置提醒会请求通知权限，若选择“不允许”，任务仍会保留但不会弹出通知，可在系统设置中为应用开启通知后重试。
3. **企业注册要求上传证明**：模拟器相册为空时无法选图，可先在模拟器相册中保存一张图片，或直接在 `数据工具 → 生成演示学生` 演示其他功能。
4. **能力画像长图导出失败**：需保证海报区域已在屏幕上完整显示（滚动到“分享海报预览”），截图仅能捕获已渲染内容。
