## 4. 图形界面运行步骤

1. 打开 DevEco Studio，`File > Open` 选择 `D:\DevEcoStudioProjects\huawei\AbilityMatch`。
2. 首次打开点击工具栏 **Sync**，等待 hvigor 与 ohpm 同步完成。
3. 检查 `File > Project Structure > SDK`，版本应为 `26.0.1`（或更高）。
4. `File > Project Structure > Signing Configs` 勾选 **Automatically generate signature**，登录华为开发者账号生成调试签名。
5. 在 **Device Manager** 启动本地模拟器，或通过 USB/WiFi 连接真机（真机需开启开发者模式与 USB 调试）。
6. 选择设备后点击 **Run**，DevEco 自动构建并安装签名 HAP。

## 5. 常见问题与处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Invalid value of 'DEVECO_SDK_HOME'` | 命令行环境未设置该变量 | 按 3.3 先设置 `$env:DEVECO_SDK_HOME`，或写入系统环境变量 |
| `ohpm` / `hvigorw` 不是可识别命令 | 工具不在全局 PATH | 用第 2 节绝对路径调用，或把两个 `bin` 目录加入 PATH |
| `JDK version too low (< 21)` | 系统 JDK 低于 21 | 可忽略（自动切换内置 JDK 21）；或设置 `JAVA_HOME` 指向 DevEco 的 `jbr` |
| `No signingConfig found` | 未配置签名 | 只影响安装，不影响编译；按第 4 步配置自动签名 |
| 资源引用 `$media:app_icon` 报错 | 图标资源缺失 | 本机已确认 `app_icon.png`、`icon.png`、`startIcon.png` 均存在 |
| 预览器白屏 | 页面未注册 | 检查 `entry/src/main/resources/base/profile/main_pages.json` 是否包含 13 个页面路径 |
| 提醒不触发 | 未授予通知/提醒权限，或运行在预览器 | 需真机或模拟器运行；提醒由 `reminderAgentManager` 注册，预览器不支持 |

## 6. 工程目录与依赖

```text
AbilityMatch/
├── AppScope/app.json5              # bundleName、版本、应用图标与名称
├── entry/src/main/
│   ├── module.json5                # Ability 声明、设备类型、权限（PUBLISH_AGENT_REMINDER）
│   ├── ets/entryability/           # 应用入口，启动时初始化 RDB 与 Preferences
│   ├── ets/pages/                  # 13 个功能页面
│   ├── ets/model/                  # 实体、枚举
│   ├── ets/common/                 # DbHelper / PrefsHelper / FileHelper / TextMatcher / Constants
│   ├── ets/repository/             # 9 个 RDB 数据访问类
│   ├── ets/service/                # 解析、抽取、匹配、导出、提醒
│   ├── ets/view/                   # 4 个通用组件
│   ├── ets/viewmodel/              # 共享状态
│   └── resources/                  # 字符串、颜色、媒体、rawfile（词典/模板/建议库）

└── docs/                           # 工程文档
```

应用不使用第三方运行时 SDK，技能词典与匹配规则全部内置，因此 `dependencies` 保持为空。
